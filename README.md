# HF Propagation Tracker for RVSU

![RVSU Logo](https://img.shields.io/badge/Developed%20for-RVSU-red)
![License](https://img.shields.io/badge/License-MIT-blue.svg)
![Version](https://img.shields.io/badge/Version-2.7.1-green)

A professional Android application designed for radio amateurs, providing real-time ionospheric propagation data and solar indices. This tool was developed specifically for RVSU (Radioamatori Voluntari în Situații de Urgență) to assist in emergency communications and daily radio operations.

## 📡 What the App Does

* Real-time Solar Indices: Fetches live data for Solar Flux Index (SFI), Sunspot Number (SN), and K-Index.
* Dynamic Ionosonde Selection: Uses the GIRO network to find the nearest ionosonde station based on GPS for precise foF2 readings.
* HF Propagation Forecasting: Calculates MUF and optimal bands based on real-time ionospheric conditions.
* Visual Online Data: Integrates graphical banners from N0NBH (hamqsl.com) for VHF, MUF maps, and solar weather.
* Emergency Ready: Persistent "Last Update" display and cache support for offline/intermittent use.
* Multi-language Support: English, Romanian, and Hungarian.

## 📊 Data Sources

* NRC DRAO Penticton: Solar Flux Index (SFI).
* NOAA: Planetary K-Index.
* SIDC SILSO: Kalman-filtered Sunspot Number (SSN).
* LGDC / GIRO: Real-time ionosonde data (foF2).
* HamQSL (N0NBH): Graphical summaries.
